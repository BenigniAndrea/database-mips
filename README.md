# Database Scolastico in Assembly MIPS

Progetto universitario sviluppato al primo anno per il corso di Calcolatori Elettronici. Il programma implementa le logiche di gestione di un database scolastico, scritto interamente a basso livello.

📄 **Documentazione:** Per i dettagli completi sulle scelte architetturali, la gestione della memoria e il funzionamento del codice, si invita a consultare la **Relazione Tecnica in PDF** allegata in questa repository.

**Tecnologie:**
- Assembly MIPS
